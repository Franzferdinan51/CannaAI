# Archived implementation trees

This directory preserves older CannaAI implementations that are not part of the active build.

- `new-ui/` is the earlier Vite/React integration layer. The maintained frontend is `NewUI/cannaai-pro/`.
- Superseded experimental agent services were removed from the maintained application. This directory contains historical UI snapshots only.

These files are retained for feature history and recovery. They are not included in the root build, test, or startup commands.
