## Organization

- `user/` and `photo-analysis/` contain end-user guidance.
- `knowledge-base/` contains troubleshooting and frequently asked questions.
- `guides/` contains maintained operational and feature guides.
- `developer/` contains architecture, API, and integration contracts.
- `integrations/` contains provider and agent integration notes.
- `archive/` preserves historical reports, migration notes, and superseded plans for reference.

When behavior changes, update the maintained guide and verification commands first. Historical reports should remain in `archive/` rather than being presented as current instructions.
