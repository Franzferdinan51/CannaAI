# CannaAI — full work-up, 2026-11-04

Audited at Duckets' request ("so old and outdated"). Verdict up front:
the bones are NOT old — the stack is current. What's stale is the
plumbing around it: the sensor pipeline was dead, the analytics
rollup had no writer, the app holds no live grow data, it listened
on every network interface, and five deployment targets + two
frontends grew around a single-user local app.

## What it is

- Next.js 16 + custom `server.ts` (Socket.IO + ws), Prisma 6.19 /
  SQLite, React 19, Tailwind 4. 482 TS/TSX files, **143 API routes**,
  38 Prisma models, 103 dependencies, 79 test files, CI workflows
  present, only 2 TODO/FIXME in `src`. Code hygiene is decent.
- Live on Robin (grow-room box): backend :3000, NewUI (Vite) :5174,
  brains via the LM Studio tunnel to the Mac, vision pinned to
  ornith-1.5-9b. Health check at audit time: db ok, lmstudio ok
  (36 models), openclaw ok (ACP), hermes unconfigured.

## Findings

1. **Sensor pipeline was dead (headline).** Schema + ingest endpoint
   (`POST /api/sensors/ac-infinity`, VPD computation, threshold
   alerts) are well built, but nothing had posted since ~2026-11-01
   (942 readings, all stale). The Mac's AC Infinity API feed only
   writes the dashboard bridge JSON since 2026-11-03; the old
   phone-scrape path is retired. Only the 3x3 Tent had a Sensor row.
2. **Analytics rollup orphaned.** `/api/analytics/sensors` reads the
   `SensorAnalytics` table — which had **no writer anywhere** in the
   codebase. The dashboard's sensor analytics were permanently
   empty while readings piled up in `SensorReading`.
3. **The app holds no grow.** Plant / Room / Strain / Task tables
   are all empty; 5 analyses total. The app can't track the actual
   grow (strawberry kush, purple sunshine, Bluntforce fauna,
   Kazakhstan landrace) until rooms + plants are seeded.
4. **Exposure.** Backend and frontend bound 0.0.0.0 on Robin — LAN
   reachable, against the standing tailnet-only rule for that box.
   NODE_ENV stays unset (dev mode) because production mode 503s
   without an auth token (the known P1-2 trap) — the auth story
   (next-auth beta, effectively unused) needs a deliberate decision,
   not an accident.
5. **Drift.** Robin's running package.json bumped next to ^16.4.2 vs
   the repo's 16.3.2 — one line, uncommitted, plus untracked .bak
   files in the live tree (dev.db backup, an old parser .bak).
6. **Sprawl.** Dockerfile, docker-compose, k8s/, netlify.toml,
   ecosystem.config.js (pm2) — five deploy targets for a local app.
   Two frontends: Next pages in src/app AND NewUI/cannaai-pro (the
   live one). Dev/test pages (socket-test, test-lmstudio) ship in
   the tree. `@google/generative-ai` cloud dep sits in a local-first
   app.
7. **Integrations half-alive.** OpenClaw health reports ok over ACP
   now that OpenClaw runs on Robin again — but it isn't wired as a
   real chat/analysis provider. Hermes provider: unconfigured (a
   Hermes also lives on Robin now). MQTT dep present, unused by the
   current sensor path. The Clone Chamber controller has **no
   climate probe attached** (sentinel values in the API) — it can
   report port states only, no temp/RH.

## Plan

- **Phase A — fixes.** Bind backend + frontend to the tailnet IP
  only; reconcile the next bump into the repo; clear the .bak
  clutter from the live tree; keep NODE_ENV as-is until the auth
  decision is made (documented, deliberate).
- **Phase B — sensor data.** Robin-native AC Infinity collector
  (`scripts/acinfinity-collect.py`, deployed to Robin
  ~/tools/aci/): systemd timer every 5 min, reads both controllers
  via the `aci` cloud API library, POSTs to
  `/api/sensors/ac-infinity` (inside temp/RH/VPD + port states).
  Ingest now also mirrors each reading into SensorAnalytics, and
  `scripts/backfill-sensor-analytics.ts` repairs the history.
- **Phase C — make it a grow app.** Seed Rooms (3x3 Tent, Clone
  Chamber) and the current strains/plants; wire the Pixel 6 /
  ~/plants photo flow into PlantAnalysis on the pinned vision
  model; configure the Hermes + OpenClaw providers that now live
  on the same box; daily grow report (DailyReport model exists).
- **Phase D — cleanup (Duckets' call).** Pick one frontend
  (recommend NewUI, retire the Next pages or vice versa), prune
  deploy targets to the one actually used (systemd on Robin),
  drop the unused cloud dep.
